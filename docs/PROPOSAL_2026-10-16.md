### SNN adjacency: repo changes when built

- `snn/__init__.py, snn/__main__.py (new)`: Package and CLI: `python -m snn weekly | watch | replay | report | status`. weekly = learn the closed ISO week once, read out, write ideas, score old ideas, write data/snn/last_run.json. replay = rebuild state from all history snapshots. Exit 0 on success; never raises into the service. Imports neither publisher nor service.notify.
- `snn/lif.py (new)`: NumPy LIF neurons + STDP with delay banks (0, 1, 2, 4 weeks): symmetric within-week window, weakening only when a lead fails, soft bounds, weekly forgetting 0.995, uint16 evidence counters, adaptive thresholds, event-driven updates, compressed .npz checkpoints, 400 MB self-stop. No new dependency.
- `snn/encode.py (new)`: The compliance boundary. It reads research.history.load() and keeps only name, date and the yes/no facts: seen(), qualified, lead (shop_count >= 2 or keyword_rows > 0, as in service/searchlist._is_lead), first seen, streak. It marks 'asked' from data/search_lists/*.json (non-seed lines from the last 2 lists, same niche, shared main word).
