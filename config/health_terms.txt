# Health topics. CLAUDE.md "No medical or therapeutic claims"; user decisions of 2026-10-16
# and 2026-10-17 (docs/HEALTH_TERMS.md, "Decided 2026-10-17").
#
# Same format and matching as trademark_blocklist.txt (whole words, plural/possessive "s",
# case and accents ignored, hyphen/space/joined spellings of a phrase):
#   plain line = MEDICAL topic: hard block everywhere (themes, briefs, listing text, printed
#                text, file names, image prompts, search lists, KDP fields)
#   ?term      = BORDERLINE: not blocked, the item waits for the user's review
# No "!" lines here. core.compliance.Blocklist.load reads this file next to the trademark
# file and remembers which terms came from it, so messages say "health topic".
#
# NOT listed, on purpose (allowed, described by layout and look): meditation, mindfulness,
# breathwork, yoga, stress, stress relief, worry, exercise, workout, fitness, gym, running,
# sleep, mood, feelings, gratitude, affirmations, habit, water intake, self-care, wellness,
# food diary / food journal / food log, meal planner, anxiety, anxious, mental health
# (so no "health journal" entry: a mental health journal is allowed),
# ADHD / ADHD-friendly, neurodivergent, skincare routine, calm, relaxing, zen.
# Result claims ("reduces anxiety", "improves sleep") are core/health.py, not this file.
# Short words with ordinary uses appear only inside phrases: pain (no pain no gain), pill
# (pill bug; the plural "pills" is listed: a pills sticker is a medicine theme), cancer (zodiac), stroke (brush stroke), contraction (grammar), period (class
# schedule, pay period), sugar (sugar cookie), fever (spring fever), pressure, dose, cycle,
# recovery, panic, temperature, injection (fuel injection), health (the TTRPG "Health" field, "healthy habits").
# Never listed because TTRPG sheets print them: medicine, psychology, sanity, wound(s),
# dying, first aid, injuries, madness, phobias, fatigue, conditions.
